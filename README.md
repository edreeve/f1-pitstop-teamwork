# The Pinnacle of Teamwork — F1 to Medical Affairs Governance

An animated, offline-ready 16:9 HTML presentation deck introducing project governance and RACI through the **Formula 1 × NHS** case study (Great Ormond Street Hospital & Williams F1 × University Hospital of Wales, Cardiff).

## Live Links (GitHub Pages)

- **Main Presentation (Clean):** https://edreeve.github.io/f1-pitstop-teamwork/
- **Survey Tiger Pilot Edition:** https://edreeve.github.io/f1-pitstop-teamwork/tiger.html

## Presenter Controls (Works with Wireless Clickers)

| Action | Key / Control |
| :--- | :--- |
| Next animation / slide | `Click`, `→`, `Space`, or `PageDown` |
| Previous animation / slide | `←`, `PageUp`, or `Backspace` |
| Fullscreen mode | `F` |
| Replay 1.92s Pit Stop (Slide 2) | `R` |
| Toggle Speaker Notes | `S` or `N` |
| Slide Overview Grid | `G` |
| Reveal all steps on current slide | `A` |
| Export 16:9 PDF backup | `PDF` button in bottom-right HUD |

## Making Last-Minute Updates

Edit `index.html` (or `tiger.html`) and push to `main`. GitHub Pages automatically updates the live URL within ~30–60 seconds—just refresh the browser tab.
